## 0. 项目是什么

**书山（Book Mount）**：Windows 桌面工具（Python + PySide6），把"中意文献的格式"
提取成可复用的格式方案（`.fprof.json`），再一键套用到自己的文档上。当前状态：
**M0/M1 已完成并公开发布**（GitHub: Care-for-Empty-Nest-Mother/Book-Mount，Release
v0.1.0 已带 exe），本次任务 = **执行 M2 里程碑**。

## 4. 关键数据流（整稿一条链）

```
用户选方案+目标docx → 批注视图确认：
  assignment {段落号:类型}（含 "ignore"）
  numbered   {标题段落号:是否参与编号}
  fmt_overrides {段落号:格式spec}（右键修改格式）
+ numbering_override (mode, scheme_levels)
  mode ∈ auto/keep_target/reference/manual/custom
→ apply.py: 
  1) analyze_document（原样格式/建议/对象/引用）
  2) resolve_assignment（override > 对象段按内容 > mapping > 建议）
  3) 备份 → render_styles_into（样式/编号注入，keep_target 保留样式级编号）
     → apply_page_setup
  4) 逐段：ignore跳过 / 未勾选标题=仅大纲级别 / 套样式+清直接格式
     / 非标题段编号结构保留(reattach) / fmt_overrides 直接格式落地
  5) protect_object_paragraphs（固定值行距豁免）+ normalize_tables（跨页规范）
     + normalize_citations（引用上标）+ fit_oversized_figures（超版心缩放）
  → 报告 dict（计数/警告/备份路径）
```

## 5. M2 需求（用户已确认的范围）

### 5.1 页眉页脚页码（profile: `header_footer`，schema 已有定义）

```jsonc
"header_footer": {
  "header": { "enabled": true, "content": "XX大学硕士学位论文", "align": "center",
              "font": {"font_cn": "宋体", "size_pt": 9},
              "different_first": false, "different_odd_even": false },
  "footer": { "enabled": true,
              "page_number": { "position": "center",
                               "format": "第 {page} 页 共 {pages} 页",
                               "start_at": 1, "start_section": "body" } },
  "body_starts_new_section": true
}
```

实现要点（新文件 `shushan/render/page_furniture.py`）：
- `apply_headers_footers(doc, hf_cfg, body_section_idx)`：对 python-docx 的
  section.header/footer 清空后写入内容（字体/对齐按 spec）；页码用 **PAGE/NUMPAGES
  域**（`w:fldSimple w:instr=" PAGE \* MERGEFORMAT "` 内嵌占位 run）；`{page}`/`{pages}`
  token 解析；different_first → `section.different_first_page_header_footer=True`
  （首页页眉页脚留空）；different_odd_even → 文档级
  `doc.settings.odd_and_even_pages_header_footer=True`（v0.2 仅开关，奇偶内容相同，
  文档里注明）。
- **正文起编**：`body_starts_new_section=true` 时，页码重启应用到**第一个正文级
  标题所在节**（body_section_idx 由 apply.py 用 assignment 找第一个 heading 段
  所在节传入）；该节之前的节（封面/摘要）页眉页脚**清空并断开链接**
  (`is_linked_to_previous=False` + 空段落)，页码 `w:pgNumType w:start` 写入该节
  sectPr。多节文档（用户的论文12有 9 节）必须按节处理，不要全局一刀切。
- 全部 try/except 包裹，失败不阻断整稿（警告进报告）。

### 5.2 目录（profile: `toc`）

```jsonc
"toc": { "levels": 3, "leader": "dot", "page_number_align": "right", "insert": true }
```

- `insert=true` 且文档内**尚无 TOC 域**（检测：正文 XML 含 `instrText` 且
  内容含 "TOC"）→ 在**第一个 heading 段之前**插入 TOC 域段落
  （fldChar begin + instrText `TOC \o "1-{levels}" \h \z \u` + separate + 占位文字
  "（目录：右键→更新域）" + end）。
- 文档已有 TOC → 不插，只在 settings.xml 写 `<w:updateFields w:val="true"/>`
  让 Word 打开时自动刷新域。
- **无论 insert 与否都写 updateFields**（整稿后页码/引用域需要刷新）。
- 方案若定义了 toc_1~3 样式 → 由既有渲染管线自动注入，TOC 域生成条目自然套用。

### 5.3 表格内部文字重排（profile: `tables.cell_style`）

```jsonc
"tables": { "repeat_header": true, "cant_split_rows": true,
            "cell_style": { "font_cn": "宋体", "font_en": "Times New Roman",
                            "size_pt": 10.5, "alignment": "center" } }
```

- `restyle_table_cells(doc, cell_style)`：遍历全部表格全部单元格的全部段落
  （python-docx `doc.tables`→rows→cells→paragraphs），把 cell_style 以**直接
  格式**写入 run（字体 eastAsia/ascii、字号、加粗不加粗、对齐段落级）。
  不改单元格文字内容，不动表格结构（列宽/合并跨页设置保持）。
- 提取侧：`docx_analyzer` 统计参考文档表格单元格段落的多数派格式（字体/字号/
  对齐）→ `analysis.table_cell_style` → profile_builder 写入 `tables.cell_style`。

### 5.4 明确不做（写进交付说明）

- 题注 SEQ 域（会把文字里的"图1-1"改成域）→ 推迟到 M3 新文档骨架，避免改内容；
- 奇偶页不同的页眉内容（仅做 Word 开关）；
- 页眉页脚的 COM 实时路径（实时路径已整体下线）。

### 5.5 提取侧（analyzer 自动填充方案新字段）

- `header_footer`：读参考文档第一节 header/footer 的文字/对齐/字体，footer 里
  PAGE/NUMPAGES 域还原成 `{page}/{pages}` 模板（`w:instrText` 含 "PAGE"/"NUMPAGES"），
  different_first/odd_even 读 sectPr 标志 → 自动写入方案（参考文档没有就缺省）。
- `tables.cell_style`：表格单元格段落格式的多数派（参考 §5.3 字段）。

## 8. 已知的坑（前人踩过，别再踩）

- **python-docx 的多级编号支持很弱**：编号全部走直接 XML（numbering_xml.py）；
- **打包复制陷阱**：`cp 文件 dist/BookMount/profiles/` 在目录不存在时会创建出
  **名叫 profiles 的文件** → 启动崩溃 WinError 183（已修复+自动免疫，
  paths.py 有自愈逻辑；重装时先 mkdir 再 cp）；
- **Defender 首次扫描**：新 exe 首次启动可能 10~30 秒无窗口，属正常；
- **.gitignore 条件替换两次失效**导致 tests/zip 两次混入远程——改 .gitignore
  必须**整文件重写**，禁止条件 replace；
- **GitHub 同名删库重建后几秒内，API 会返回旧仓库的缓存树**——验证远程用
  本地 `git ls-tree <pushed_sha>` 为准；
- Bash heredoc 内嵌含反斜杠的补丁会翻车（unicodeescape/换行断裂）——
  用 Edit 工具或补丁脚本文件；
- 窗口化 exe 无控制台：启动异常写 `启动错误.log`（main.py 已实现）；
- 用户会随时移动文件——涉及用户文件的命令先确认文件还在。
